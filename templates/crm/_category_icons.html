{# ══════════════════════════════════════════════════════════════════════════ Business category icons — one line-drawn set ══════════════════════════════════════════════════════════════════════════ The codebase already has an icon convention, and this file follows it rather than inventing one. The precedent is `.perf-icon` (static/css/cr-design.css L738) with its mark-up in templates/transactions/list.html L326+: an inline SVG, no sprite and no icon font, `fill: none`, the shape carried by a stroke, `stroke-linecap: round` and `stroke-linejoin: round`, drawn at a light weight. lucide-react is not available here; this is server-rendered Jinja, so every icon is written out inline. THE STYLE RULES — a future icon must keep all six: 1. viewBox "0 0 24 24", with roughly 2px of clear margin inside it, so the drawings share one optical size whatever the rendered box. 2. fill="none" — line-drawn, never filled, never two-tone. 3. stroke="currentColor" — the icon inherits the CRM's ink colour, so it can be muted or inverted by the surrounding class alone. 4. stroke-width 1.6, the same on all sixteen. This is `.perf-icon`'s 1.3 on a 16px box, rescaled to a 24px box. 5. stroke-linecap and stroke-linejoin both "round". 6. Simple beats detailed: these are read at 38–56px.
